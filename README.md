# React + TanStack Query Events App

A full-stack React application demonstrating asynchronous state management, server mutation, and caching using **TanStack Query (React Query)** paired with a **Node.js/Express** REST API backend.

## 🚀 Live Demo

- **Frontend (Vercel):** [https://tan-stack-query-sooty.vercel.app/](https://tan-stack-query-sooty.vercel.app/)
- **Backend API (Railway):** [https://tanstack-query-production.up.railway.app/events](https://tanstack-query-production.up.railway.app/events)

## ✨ Features

- **Optimistic Updates & Mutations:** Create, edit, and delete events with instant UI feedback using TanStack Query.
- **Search & Filtering:** Real-time event search powered by query key invalidation.
- **Image Selection:** Static file serving for event media hosted on Express.
- **Cross-Platform Deployment:** Frontend hosted on Vercel and Node.js backend hosted on Railway.

## 🛠️ Tech Stack

- **Frontend:** React, Vite, TanStack Query v5, React Router DOM
- **Backend:** Node.js, Express, CORS, Body-Parser
